# Agile, Scrum Master & Kanban Learning Journey 🚀

Welcome to your practical learning repository! This is your central hub for mastering Agile methodologies, Scrum Master certification, and Kanban frameworks.

## 📚 Learning Roadmap

### **Phase 1: Foundations (Weeks 1-2)**
- [ ] Understand Agile Manifesto & Principles
- [ ] Learn Scrum Framework basics
- [ ] Kanban fundamentals
- [ ] Jira setup & basics

### **Phase 2: Deep Dive (Weeks 3-4)**
- [ ] Scrum ceremonies & roles
- [ ] Sprint planning & estimation
- [ ] Backlog refinement
- [ ] Kanban metrics & flow

### **Phase 3: Advanced (Weeks 5-8)**
- [ ] Scrum Master responsibilities
- [ ] OKRs & goal setting
- [ ] Product roadmapping
- [ ] Scaling Agile (SAFe/LeSS)

### **Phase 4: Certification & Practice (Weeks 9+)**
- [ ] Scrum Master Certification Prep (PSM I)
- [ ] Hands-on Jira/Kanban practice
- [ ] Lead/facilitate mock sprints
- [ ] Real-world project application

## 🎯 Key Topics to Master

1. **Agile Principles** — Flexibility, collaboration, customer focus
2. **Scrum Framework** — Roles, ceremonies, artifacts
3. **Kanban Methodology** — Continuous flow, WIP limits, visualization
4. **Product Management** — Roadmaps, user stories, prioritization
5. **Tools Proficiency** — Jira, Confluence, GitHub Projects
6. **Certification** — PSM I (Professional Scrum Master)
